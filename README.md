# Nutrient Interaction Engine

An R research project for exploring nutrient amounts, forms, meal context and
chronology through source-backed absorption findings, visualizations and JSON.

Development plan: [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md).

Initial version under development. Evidence coverage and numerical predictions
will be documented as they become available. Unknown effects are explicit.

## Development

Open `nutrient-engine.Rproj` in RStudio. Setup and usage instructions will be added
with the first working engine. Commit credentials and private health data nowhere
in this repository.
